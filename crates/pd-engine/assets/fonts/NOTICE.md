# Bundled fonts

These font files are embedded into the PrismDesk binary (via `include_bytes!`).

- **Geist** and **Geist Mono** — © 2023 Vercel, in collaboration with basement.studio.
  Licensed under the SIL Open Font License, Version 1.1 (OFL-1.1).
  Source: https://github.com/vercel/geist-font (v1.8.0)

- **Lucide** (`lucide.ttf`) — icon font from the Lucide project.
  Licensed under the ISC License.
  Source: https://github.com/lucide-icons/lucide (npm `lucide-static`)

Full license texts ship with the upstream projects; the installer bundle should
include the OFL-1.1 and ISC texts alongside the application.
